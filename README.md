# Игры для учеников

Работают без интернета: откройте файл в браузере (озвучка лежит в папках `audio/` и `audio_en/`).

**Китайский** (учебник «Время учить китайский! 9», уроки 1–3)
- `index.html` — «Шахта ключей»: ключи иероглифов.
- `nedelya.html` — «Задания недели» (школьные задания 16–19 ноября): прописи с проверкой каждой черты (4 шага), письмо фраз, иероглифический диктант, слова уроков 1–2, грамматика 了 (шпаргалка со слайда, 7 предложений из ДЗ, «了 или не 了?»).
- `kuhnya.html` — «Кухня слов»: 66 слов и 47 предложений для диктанта, плюс блок «Домашнее задание: суффикс 了» (шпаргалка со слайда, игры «Где стоит 了?» и бегалка, ответы с объяснениями).

**Английский** (начальный уровень A1)
- `english.html` — «English Craft»: 65 слов и 40 предложений по трём темам (семья; еда и животные; школа и действия).
  Слова: диктант на слух, собери слово из букв, напиши слово, «Как пишется?», что значит, мемори, охота за картинками (бегалка), крипер-босс, книга.
  Предложения: собери предложение, пропущенное слово, переводчик, стройка предложений (бегалка).

В начале игры (английская версия — при каждом запуске) ученик вписывает имя или ник: прогресс хранится отдельно для каждого имени (в браузере устройства).
Озвучка: нейросетевые голоса Microsoft (китайский — `zh-CN-XiaoxiaoNeural`, английский — детский `en-US-AnaNeural`), записаны заранее.

Сайт: включите GitHub Pages — Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
