# Игры для Миши — китайский язык

Учебник «Время учить китайский! 9». Обе игры работают без интернета: откройте файл в браузере.

- **`index.html` — «Шахта ключей»**: ключи иероглифов, уроки 1–3.
- **`kuhnya.html` — «Кухня слов»**: подготовка к диктанту по урокам 1–3. Слова (66) и предложения из текстов учебника (47):
  собери предложение, пропущенное слово, пиши в тетради, диктант на слух, собери слово, пиши по памяти, тоны, мемори, крипер-босс, книга слов и предложений.
  Уроки для повторения переключаются в меню.

Сайт: включите GitHub Pages — Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
