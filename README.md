# Игры для Миши — китайский язык

Учебник «Время учить китайский! 9». Игры работают без интернета: откройте файл в браузере (озвучка лежит в папке `audio/`).

- **`index.html` — «Шахта ключей»**: ключи иероглифов, уроки 1–3.
- **`kuhnya.html` — «Кухня слов»**: подготовка к диктанту по урокам 1–3 (66 слов и 47 предложений из текстов учебника).
  Для предложений: собери предложение, пропущенное слово, переводчик (с русского на китайский + написать слово),
  стройка предложений (бегалка). Для слов: диктант на слух, собери слово, пиши по памяти, тоны, мемори, крипер-босс, книга.
- В начале игры каждый ученик вписывает своё имя или ник: прогресс хранится отдельно в браузере для каждого имени.
- Озвучка: нейросетевой голос Microsoft (`zh-CN-XiaoxiaoNeural`), записан заранее в `audio/`.

Сайт: включите GitHub Pages — Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
